Caveats

  • Cohort layering assumes the same population applies after removal; alerts also deter bad risks, so every cost line here is a floor, not an estimate (Zero Alerts README s7).
  • Published v0 ledger this config must reproduce: What Must Be True v4 s2 and Zero Alerts README s4.
  • Selection-effect floor: at the projected un-reviewed rate (9.0 [7.0 .. 11.0] per 100) the NOC line becomes +48 [+18 .. +83] per month. The headline uses the measured twin and is therefore a floor.
  • Name your NOC denominator: every rate above is per 100 BOUND policies of this cohort, inspection-lane NOCs, first 90 days. Darren's 11.7% is every UW NOC, book-wide. Never mix them.
  • Ranges are worst-case interval propagation, so they are wider than any single hand-computed bracket; a hand range should sit inside the machine's range.
  • The priced dollar lines are NOT the verdict: still unpriced -> GWP from new binds; NOC cost, agent attrition; NOE cost, customer side; Effect on loss ratio.
